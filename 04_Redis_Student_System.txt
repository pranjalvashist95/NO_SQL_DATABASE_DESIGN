PRACTICAL 4 — Redis student key/value system
Run each command in redis-cli after Redis server is running.

DEL student:1 student:2 student:3 student:4 student:5
SET student:1 "Aarav Sharma"
SET student:2 "Ananya Verma"
SET student:3 "Rohan Singh"
SET student:4 "Meera Gupta"
SET student:5 "Kabir Joshi"

# Retrieve one student by key
GET student:3

# Update a student's value
SET student:3 "Rohan Singh (Updated)"

# Delete a student
DEL student:5

# Display keys belonging to this exercise (SCAN is preferred to KEYS in production)
SCAN 0 MATCH student:* COUNT 100

Notes:
- Key-value model stores a value against a unique key.
- SET overwrites an existing key; GET retrieves it; DEL removes it.
- Redis is an in-memory data store and supports persistence/configurable durability.
